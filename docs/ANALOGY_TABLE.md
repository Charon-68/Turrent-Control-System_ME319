# Electrical-mechanical analogy for the elevation drive

Generated by `studies/tc_study_plant_response.m` from `core/tc_params.m` (nothing typed by hand). Plant: `G(s) = 1000 / ( s (320 s^2 + 3350 s + 1.0015e+06) )`.

## Element-by-element (torque-voltage / mass-inductor analogy)

| Mechanical side (turret) | Electrical side (armature) | Mechanical value | Electrical value | Role in G(s) |
|---|---|---|---|---|
| inertia `J_eq = J_t + N^2 J_m` | inductance `L` | 3200 kg m^2 | 0.10 H | both store kinetic / magnetic energy; leading coefficient `a2 = L J_eq` = 320 |
| viscous damping `b` | resistance `R` | 1500 N m s/rad | 1.00 ohm | dissipate energy; `a0` contains `R b` = 1500 |
| torque `T` | voltage `V` | `T = N K_t i` | `V` (input) | `N K_t` = 1000 N m/A scales current into turret torque |
| angular velocity `omega` | current `i` | `omega = theta'` | `i` | the two flow variables |
| (no spring) | (no capacitor) | -- | -- | no restoring torque, hence the free integrator pole at s = 0 |
| coupling | back-emf / motor torque | `N K_t` = 1000 N m/A and `N K_e` = 1000 V s/rad | -- | gyrator: the loop term `N^2 K_t K_e` = 1e+06 is what turns two lags into a resonance |

## Time constants and the resonance

| Quantity | Formula | Value |
|---|---|---|
| electrical time constant | `L/R` | 0.100 s |
| mechanical time constant | `J_eq/b` | 2.133 s |
| coupling ratio | `N^2 K_t K_e / (R b)` | 666.7 (strongly coupled: back-emf dominates the damping) |
| undamped natural frequency | `sqrt((R b + N^2 K_t K_e)/(L J_eq))` | 55.94 rad/s (8.90 Hz) |
| damping ratio | `(L b + R J_eq) / (2 sqrt(L J_eq (R b + N^2 K_t K_e)))` | 0.0936 |
| decay rate of the oscillation | `(L b + R J_eq)/(2 L J_eq)` | 5.234 1/s (time constant 0.191 s) |
| integrator gain (rate per volt) | `N K_t / a0` | 9.9850e-04 rad/s per V |

## Mechanics reflected into the armature circuit

Eliminating `omega` gives `V = (L s + R) i + Z_m i`, with motional impedance `Z_m = N^2 K_t K_e / (J_eq s + b)`, i.e. a capacitor and a conductance in parallel:

| Reflected element | Formula | Value |
|---|---|---|
| series inductance | `L` | 0.10 H |
| series resistance | `R` | 1.00 ohm |
| parallel capacitance (the inertia) | `J_eq/(N^2 K_t K_e)` | 0.0032 F |
| parallel resistance (the damping) | `N^2 K_t K_e / b` | 666.7 ohm |

So the inertia appears as a capacitor seen from the electrical terminals and as an inductor in the torque-voltage analogy above: both are correct, they use different analogies (impedance versus mobility). The series `L` with this parallel `C` is the lightly damped 55.9 rad/s resonance.

## Time response read-off

Impulse response oscillates at wd = 55.70 rad/s (8.86 Hz) with the envelope decaying as exp(-5.234 t); the step response is a ramp at 9.9850e-04 rad/s per volt plus the same oscillation (see `outputs/tc_study_plant_response.txt`, `plots/tc_study_plant_response.*`).
